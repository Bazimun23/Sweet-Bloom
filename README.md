# Sweet Bloom Bakery 🍰

A responsive bakery website prototype created as part of the Terralogic AI Challenge.

## 📌 Project Overview

Sweet Bloom Bakery is a simple and user-friendly website concept designed for small home bakeries to showcase their products and make it easier for customers to explore cakes, sweets, and ordering information in one place.

## 🎯 Problem

Many small home bakeries depend mainly on WhatsApp, Instagram, and phone calls to display their products and receive orders.

Customers may not have one central place to:

* View available products
* Explore different cake options
* Understand how to place an order
* Find bakery information easily

## 💡 Solution

Sweet Bloom Bakery provides a simple online presence where customers can:

* Browse bakery products
* View featured items
* Learn about the bakery
* Understand the ordering process
* Contact the bakery through WhatsApp

## ✨ Features

* Responsive bakery website
* Navigation menu
* Featured products section
* Product cards
* About section
* How to Order section
* WhatsApp contact button
* Mobile-friendly layout
* Responsive hamburger menu
